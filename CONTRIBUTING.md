# Contributing

Read the [contributor guide](AGENTS.md) and use the [README](README.md) to set up the project and run checks. Keep changes focused and open a pull request with the purpose, test evidence and rollback instructions. Changes require review and maintainer approval before merging.

Use fictional inputs in examples and reports. Keep credentials, personal financial data and datasets without verified reuse rights out of submissions. Report vulnerabilities using the [security policy](SECURITY.md).
