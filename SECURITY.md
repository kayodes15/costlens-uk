# Security

Report suspected vulnerabilities privately to the maintainers. Use GitHub’s private vulnerability reporting if enabled, or an existing private channel with a maintainer. Include the affected version, steps to reproduce with fictional inputs, and the expected and observed behaviour. Omit credentials and real financial inputs. Coordinate public disclosure with the maintainers after remediation.

Financial inputs and calculation results are processed in the browser. Review the [release checklist](docs/RELEASE-CHECKLIST.md) for security and privacy requirements.
